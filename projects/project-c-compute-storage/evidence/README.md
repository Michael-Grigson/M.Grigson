# Evidence Index

This folder contains implementation evidence for **Project C - Azure Compute, Storage and Scaling**.

The evidence is organised by compute, application hosting, containerisation, and storage workstreams to show the progression from core storage administration through to scalable compute, PaaS application hosting, container deployment, and secure storage design.

---

## Evidence Structure

| Folder | Purpose |
|---|---|
| `07-storage` | Evidence for core Azure Storage administration, including storage account configuration, blob containers, Azure file shares, lifecycle management, redundancy, SAS access, and network access controls. |
| `08-virtual-machines` | Evidence for Azure virtual machines, availability zones, VM resizing, managed disks, PowerShell VM deployment, Virtual Machine Scale Sets, load balancing, autoscaling configuration, SKU troubleshooting, and quota handling. |
| `09a-web-apps` | Evidence for Azure App Service deployment, runtime configuration, deployment slots, external Git deployment, production slot swaps, and web app autoscaling. |
| `09b-container-instances` | Evidence for Azure Container Instances deployment, public container access, DNS configuration, container status validation, and container log review. |
| `09c-container-apps` | Evidence for Azure Container Apps deployment, managed container app environments, quickstart container images, application URL validation, and serverless container hosting. |
| `secure-storage-for-azure-files-and-azure-blob-storage` | Evidence for secure Azure Blob Storage and Azure Files scenarios, including public and private storage access, SAS access, lifecycle management, object replication, managed identities, Key Vault integration, customer-managed keys, immutable storage, and encryption scopes. |
