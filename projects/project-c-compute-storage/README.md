# 📁 Project C - Azure Compute, Storage & Scaling  

📊 Status: 🟨 Planned  

---

## 📖 Overview  

This project will focus on the deployment and management of Azure compute, storage, and application hosting resources, with an emphasis on scalability, performance, and workload design.  

It will demonstrate how infrastructure is provisioned to support application workloads, including decisions around compute sizing, storage configuration, and platform selection across IaaS, PaaS, and container-based services.  

---

## 🎯 Scope  

The project will cover:  

- Virtual machine deployment and configuration  
- Virtual machine scale sets for horizontal scaling  
- Disk and storage performance tiers  
- Blob storage and file share configuration  
- Azure App Services for web application hosting  
- Azure Container Instances and Container Apps  
- Workload placement and availability considerations  

---

## 🧠 Key Focus Areas  

- Scaling strategies (vertical vs horizontal)  
- Storage tier selection and cost-performance trade-offs  
- High availability and fault tolerance  
- IaaS vs PaaS vs container workload decisions  
- Integration with network and security controls  

---

## 🚀 Planned Outcome  

A structured compute and application hosting environment that demonstrates:  

- Scalable workload deployment across multiple hosting models  
- Optimised storage configuration  
- Platform selection based on workload requirements  
- Alignment with Azure best practices for performance and availability
