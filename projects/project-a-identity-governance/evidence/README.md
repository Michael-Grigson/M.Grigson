This folder contains implementation evidence for \*\*Project A - Identity and Governance\*\*.



The evidence is organised by control area to make the implementation easier to review, validate, and explain. Each folder contains screenshots showing the configured Azure or Microsoft Entra components, policy settings, validation results, and supporting implementation evidence.



\## Evidence Structure



| Folder | Purpose |

|---|---|

| `01-entra-identities-groups` | Evidence for Microsoft Entra ID user creation, guest user invitation, security groups, group ownership, and group membership configuration. |

| `02-conditional-access` | Evidence for Conditional Access policy configuration, MFA enforcement, admin role protection, legacy authentication blocking, and report-only validation. |

| `03-break-glass-accounts` | Evidence for emergency access account creation, role assignment, exclusion from Conditional Access policies, and account protection review. |

| `04-rbac` | Evidence for Azure role-based access control, built-in role assignments, custom RBAC role creation, and Activity Log validation. |

| `05-policy-governance` | Evidence for Azure Policy assignments, tag enforcement, tag inheritance, remediation behaviour, and governance validation. |

| `06-resource-locks` | Evidence for resource lock configuration and deletion protection validation. |
