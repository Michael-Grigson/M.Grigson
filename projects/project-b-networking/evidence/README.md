# Evidence Index

This folder contains implementation evidence for **Project B - Azure Network Architecture and Connectivity**.

The evidence is organised by networking workstream to show the progression from core infrastructure deployment through to secure hub-spoke architecture, traffic management, routing, and validation.

## Evidence Structure

| Folder | Purpose |
|---|---|
| `03-iac-foundation` | Evidence for repeatable infrastructure deployment using ARM templates, Bicep, Azure PowerShell, Azure CLI, and Cloud Shell. |
| `04-virtual-networking` | Evidence for virtual networks, subnet design, network security groups, application security groups, and DNS zone configuration. |
| `05-intersite-connectivity` | Evidence for VNet peering, Network Watcher connection testing, private connectivity validation, and user-defined route configuration. |
| `06-traffic-management` | Evidence for Azure Load Balancer, backend pools, health probes, load balancing rules, Application Gateway, path-based routing, and backend health validation. |
| `07-secure-hub-spoke-firewall` | Evidence for hub-spoke architecture, Azure Firewall deployment, firewall rules, route tables, forced routing, DNS configuration, and validation testing. |
